# MetaLog Maintainers

The MetaLog specification is currently edited by the CodeRoast InSight maintainers.

## Current Review Areas

| Area | Responsible project |
|---|---|
| Spec text and governance | `metalog-spec` |
| Reference producer feedback | `insight-metalog` |
| Detection and explanation consumer feedback | the InSight detection/explanation consumers |
| Deterministic validation fixtures | the LogCraft generator and `logcraft-playground` |

Maintainer names and public review roles should be updated here when the spec governance opens beyond the initial CodeRoast maintainers.
